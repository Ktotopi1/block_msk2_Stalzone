# block_msk2_Stalzone
Батник (.bat) для автоматической блокировки лагающих серверов МСК-2 в STALCRAFT через Брандмауэр Windows. Помогает исправить проблемы с пингом и регистрацией урона.
# Stalcraft MSK-2 Server Blocker

Простой автоматический скрипт (.bat), предназначенный для исправления проблем с высоким пингом, лагами и задержкой регистрации урона (хитсканом) в игре STALCRAFT путем принудительной блокировки нестабильных серверов подсети МСК-2.

## Как это работает
Игра не позволяет вручную выбирать серверное зеркало в настройках. Скрипт использует встроенный инструмент Брандмауэр Windows (Windows Defender Firewall) для создания правила исходящего подключения. 

Он полностью блокирует игровой трафик (UDP-порты 29450-29460) для известных IP-диапазонов хостинга МСК-2. В результате игра физически не может подключиться к лагающему серверу и вынуждена перенаправлять персонажа на более стабильные подсети (например, МСК-1 или МСК-3).

## Особенности
* Блокировка All-in-One: Правило применяется ко всем процессам, что исключает обход блокировки через скрытые процессы Java или обновление лаунчера.
* Актуальная база IP: Включает в себя как классические диапазоны подсетей EXBO, так и новые прокси и арендованные подсети (включая Hetzner).
* Безопасность: Скрипт использует исключительно стандартные средства операционной системы Windows. Он не внедряется в память игры, не изменяет файлы клиента и не может стать причиной блокировки античитом (EXBO Anti-Cheat).
* Удаление в один клик: Скрипт автоматически перезаписывает старое правило при повторном запуске, предотвращая засорение брандмауэра.

## Инструкция по установке и запуску

1. Скачайте файл block_msk2.bat из этого репозитория.
2. Полностью закройте STALCRAFT и Steam / EXBO Launcher.
3. Нажмите по файлу block_msk2.bat правой кнопкой мыши и выберите "Запуск от имени администратора" (это необходимо для внесения изменений в правила сетевой безопасности).
4. Дождитесь сообщения об успешном создании правила и закройте окно.
5. Запустите игру.

## Как отключить блокировку
Если вам по какой-то причине снова потребуется доступ к серверам МСК-2, вы можете удалить правило одним из способов:
1. Через PowerShell: Откройте PowerShell от имени администратора и выполните команду:
   Remove-NetFirewallRule -DisplayName "STALCRAFT MSK BLOCK"
2. Вручную: Откройте Монитор брандмауэра Защитника Windows (wf.msc), перейдите в Правила для исходящего подключения, найдите правило STALCRAFT MSK BLOCK и удалите его.
